Importer des enseignants (CSV)

Créez plusieurs fiches d'un coup à partir d'un fichier CSV (Excel → « Enregistrer sous » → CSV). Chaque fiche reçoit un code ; complétez-la ensuite ou laissez l'enseignant la compléter.

Colonnes reconnues (1re ligne = en-têtes) : Nom (obligatoire), Établissement, Téléphone, E-mail, CRE, Grade, Matricule. Séparateur « ; » ou « , ».

Envoi automatique du code (EmailJS)

Pour que le code parte automatiquement par e-mail dès qu'un enseignant enregistre sa fiche, créez un compte gratuit sur emailjs.com, un « service » (connectez votre Gmail) et un « template », puis collez ci-dessous les 3 identifiants. Sans ça, le bouton « Recevoir le code par e-mail » reste disponible.

Le template doit contenir les variables {{to_email}} (destinataire), {{code}} et {{message}}.

Accès des enseignants à leurs fiches

En début d'année, ouvrez l'accès pour que vos enseignants mettent à jour leur fiche (par code) pendant une période déterminée. Hors de cette période, les fiches sont verrouillées (non consultables par code). Vous gardez toujours l'accès complet depuis l'espace inspecteur.

Comment remplir votre fiche ?

  1. Complétez toutes les rubriques ci-dessous (les champs marqués * sont obligatoires).
  2. Remplissez votre emploi du temps : classe, salle et précision éventuelle (semaine A/B, groupe, séance d'1 h) dans chaque case.
  3. En bas, la liste de vos classes se remplit automatiquement : indiquez le nombre d'élèves de chacune.
  4. Cliquez sur Enregistrer : un code personnel vous sera attribué pour modifier votre fiche plus tard.
