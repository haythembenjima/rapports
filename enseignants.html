Comment remplir votre fiche ?

  1. Complétez toutes les rubriques ci-dessous (les champs marqués * sont obligatoires).
  2. Remplissez votre emploi du temps : classe, salle et précision éventuelle (semaine A/B, groupe, séance d'1 h) dans chaque case.
  3. En bas, la liste de vos classes se remplit automatiquement : indiquez le nombre d'élèves de chacune.
  4. Cliquez sur Enregistrer : un code personnel vous sera attribué pour modifier votre fiche plus tard.
